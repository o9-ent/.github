# .github

This is the special `.github` repository for the [o9-ent](https://github.com/o9-ent) organization.

## Organization Profile

The [profile/README.md](./profile/README.md) file contains the public organization profile that explains:
- How o9-ent serves as an enterprise-level organization
- The microcosm mapping pattern adapted for the o9 enterprise
- The hierarchical relationship with o9-glo (one level lower)
- How o9 organizations map to repositories, and org repositories map to folders

Visit the [o9-ent organization page](https://github.com/o9-ent) to see this profile in action.
